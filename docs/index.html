최신 버전 · 안드로이드 7.0 이상
아이폰은 여기서 열기
설치 방법 3단계
  1. 위 버튼을 눌러 파일을 내려받아요.
  2. 내려받은 파일을 열고, “출처를 알 수 없는 앱” 안내가 나오면 이번만 허용해요.
  3. 앱을 열고 마이크 권한을 허용하면 끝이에요. 다음부터는 앱이 알아서 업데이트돼요.
말로 쓰는 법 음성 명령
  1. “Hey Google” 또는 “하이 빅스비” 다음에 “아침 브리핑 열어 줘”
  2. 앱 안 마이크: “뉴스 알려줘”, “다음”, “멈춰”, “MBC 뉴스”, “경제 뉴스만”
  3. 확인 묻기: “신세계 폭발물 진짜야?”
아이폰에서 앱처럼 쓰기 홈 화면에 추가
  1. 사파리로 이 페이지를 열고 ‘아이폰은 여기서 열기’를 눌러요.
  2. 아래쪽 공유 버튼(네모에 위 화살표)을 누르고 ‘홈 화면에 추가’를 골라요.
  3. 홈 화면의 ‘아침 브리핑’ 아이콘으로 열면 돼요. 화면을 켜 둔 동안 읽어 주고, 말로 하고 싶으면 입력창에서 키보드의 마이크를 눌러요.
